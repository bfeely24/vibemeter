Evalon supports three distinct authentication methods.

Password Validation

User enters password in ChoosePassword

Check Biometrics Availability

Display Error Message

Key features

Password sign-in: ChoosePassword validates the password against the policy in auth/passwordRules.ts before creating a session.

Biometric unlock: After a valid password, users can enroll Face ID or fingerprint; BiometricGate checks device support first.

Graceful fallback: When biometrics are unavailable or declined, sign-in continues with the password and the choice is stored per device.

Single sign-on: Enterprise orgs authenticate through SAML or OIDC via SsoProvider, which maps identity claims to organization roles.

Note: Session tokens are refreshed by AuthProvider and revoked on sign-out across all three methods.

Tech Stack

Authentication is built on React Native with Expo LocalAuthentication for biometrics, secure token storage in the device keychain, and a Node.js auth service that issues short-lived JWTs backed by refresh tokens.

The ComparePage fetches job details for two batches to display a comparison table. Previously, all jobs were fetched in a single query:

const gulp = require('gulp');
const util = require('./build/lib/util');
const path = require('path');
const compilation = require('./build/lib/compilation');
// Fast compile for development time
gulp.task('clean-client', util.rimraf('out'));
gulp.task('compile-client', ['clean-client'], compilation.compileTask('out', false));
gulp.task('watch-client', ['clean-client'], compilation.watchTask('out', false));

This caused double-fetching: when batch2 arrived after batch1, allJobIds changed, invalidating the cache and refetching all jobs including batch1's. The fix uses useQueries to cache each job independently, so only new job IDs trigger fetches.
